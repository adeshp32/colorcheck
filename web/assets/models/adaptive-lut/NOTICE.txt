ColorCheck uses the upstream pretrained paired sRGB weights. ColorCheck did not
train these weights. The classifier was adapted for a reproducible ONNX export
that returns a weighted lookup table instead of using the native interpolation
extension. Full-resolution interpolation and adjustable safeguards are separate
ColorCheck code. Enhancement is experimental, not reference matching.
